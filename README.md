🚀 Weather Report Application – React Project

I’m excited to share my latest React project – Weather Report Application 🌤️💻

This project allows users to search for any city and view real-time weather information using the OpenWeatherMap API.

✨ Key Features:

🌍 Search weather by city
🌡️ Temperature & Feels Like
💧 Humidity & Wind Speed
☀️ Weather condition & description
❌ Error handling
📱 Responsive design

🛠️ Technologies Used:
React | JavaScript | HTML | CSS | Axios | OpenWeatherMap API

📚 What I Learned:
Through this project, I gained practical experience in React Hooks, API Integration, Axios, State Management, Error Handling, Dynamic Rendering, and Responsive Web Design.
